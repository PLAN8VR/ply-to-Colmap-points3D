# ply-to-Colmap-points3D
A simple script to convert a .ply pointcloud file to COLMAP's points3D file format.

Dependancies = plyfile

'pip install numpy plyfile'

Place your .ply file (named clean.ply) in the same folder as the script, run the script using 

'python ply_to_points3D.py'

Choose  .txt or .bin 

Boom.
